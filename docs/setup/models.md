Агент в режиме ask проанализировал файл, понял, что он в режиме ask и не может сам менять файлы, описал ответ на запрос и посоветовал, как самому это сделать.
Агент в режиме code полностью реализовал поставленную задачу.
Вывод: для того, чтобы понять как работает какая-то часть кода, или как пофиксить баг(не меняя код), выбираем ask. Если нужно уже непосредственно делать правки в коде, используем режим code.

code - есть все доступы. Чтение файлов, редактирование.
ask - только читает, не может писать в файлы. Для анализа и ответов на вопросы.
plan - может писать план для выполнения задач
